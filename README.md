# Wplace Click Assistant

基于 OpenCV 颜色检测的自动化绘画工具，用于 **Wplace** 平台的像素绘制。

## 关于本项目

本脚本最初由 [@Beibeisheep](https://github.com/Beibeisheep/Wplace-Click-Assistant) 开发，在原版基础上进行了大量重构和功能扩展：

- 重写检测逻辑，支持 **全色模式** 和 **免费色模式** 自动遍历
- 新增 **自动翻页** 功能（WASD 方向）
- 新增 **取色区** 定义，自动定位颜色按钮
- 优化矩形合并算法，支持拖画路径
- 精简全局状态，消除多个死锁和竞态 bug
- 添加 GUI 状态窗口，实时显示进度

## 功能

- **单色模式** — 指定一种颜色，自动检测并绘制所有匹配区域
- **全色模式** — 按颜色库顺序遍历所有颜色，逐色绘制
- **免费色模式** — 仅遍历免费颜色，适合免费用户
- **自动翻页** — 支持 WASD 方向自动翻页，翻页后继续绘制
- **区域排除** — 可定义排除区域，避免绘制到不想覆盖的位置
- **取色区** — 定义取色区域，自动定位颜色选择按钮

## 安装

### 依赖

```bash
pip install pyautogui numpy opencv-python pygetwindow pynput keyboard mss scikit-learn
```

> `mss` 为可选依赖，用于更快的截图。未安装时会自动回退。

### 运行

```bash
python pixel_painter_next.py
```

## 使用

### 热键

| 按键 | 功能 |
|------|------|
| `1` | 单色模式 |
| `2` | 免费色模式 |
| `3` | 全色模式 |
| `Z` | 启动 / 暂停 |
| `Q` | 取色（单色模式下，鼠标所在位置） |
| `W/A/S/D` | 自动翻页（上/左/下/右） |
| `O` | 进入区域定义模式 |
| `F9` | 定义模式下添加点（两次 F9 确定矩形） |
| `F10` | 保存当前定义的区域 |
| `G` | 返回模式选择 / 退出 |

### 区域定义

按 `O` 进入区域定义模式，每次按 `O` 会循环切换三种区域类型：

1. **排除区** — 该区域内的目标不会被绘制
2. **取色区** — 在该区域内查找颜色按钮并点击
3. **免费取色区** — 同上，用于免费颜色模式

定义步骤：
1. 按 `O` 选择区域类型
2. 移动鼠标到第一个角，按 `F9`
3. 移动鼠标到对角，按 `F9`
4. 按 `F10` 保存

### 工作流程

1. 运行脚本，按 `1`/`2`/`3` 选择模式
2. 按 `O` 定义取色区（可选，但推荐）
3. 切换到游戏窗口
4. 按 `Z` 开始自动绘制
5. 如需翻页，按 `W/A/S/D` 启动自动翻页

## 配置

脚本顶部可调参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TOLERANCE` | 3 | 颜色匹配容差（0-255） |
| `MOUSE_DURATION` | 0.0001 | 鼠标移动时长 |
| `SCROLL_DRAG` | 0.4 | 翻页拖拽时长（秒） |
| `SCROLL_SETTLE` | 1.2 | 翻页后等待时间（秒） |
| `WIN_TITLE` | "Paint the world" | 目标窗口标题 |
| `FULLSCREEN` | True | 是否全屏模式 |

## 技术原理

1. **截图** — 使用 `mss` 或 `PIL` 截取游戏窗口
2. **颜色检测** — OpenCV `inRange` 根据目标颜色和容差生成二值掩码
3. **轮廓提取** — 查找所有匹配区域的外轮廓
4. **矩形合并** — 按行分组，将相邻矩形合并为拖画路径
5. **模拟点击** — `pyautogui` 移动鼠标 + `keyboard` 模拟空格键绘制
